
# Cryptocurrency Volatility Prediction

## Project Overview
This project predicts cryptocurrency volatility using machine learning techniques based on historical OHLCV data.

## Features
- Data preprocessing
- Feature engineering
- Exploratory Data Analysis
- Machine Learning Model Training
- Model Evaluation
- Streamlit Deployment

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Streamlit
- Matplotlib
- Seaborn

## Project Structure

crypto_volatility_project/
